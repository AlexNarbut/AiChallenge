## 📦 Что реализовано

### 1. Архитектура (4 режима)

✅ **Быстрый ответ** (`/reasoning_basic`)
- Прямые лаконичные ответы
- Минимум слов - максимум точности
- Системный промпт: `reasoning_basic.txt` (1.7 KB)

✅ **Пошаговый ответ** (`/reasoning_math`)
- Детальное решение с объяснениями
- Структура: Анализ → Шаги → Ответ → Проверка
- Системный промпт: `reasoning_mathematical.txt` (3.0 KB)

✅ **Составление промпта** (`/reasoning_strategic`)
- Генерация промптов для других LLM
- Техники промпт-инжиниринга
- Системный промпт: `reasoning_strategic.txt` (5.6 KB)

✅ **Мнение экспертов** (`/reasoning_creative`)
- Панель из 4 экспертов (математик, психолог, программист, философ)
- Синтез различных подходов
- Системный промпт: `reasoning_creative.txt` (6.9 KB)

## 🎯 Функциональность

### Команды бота:

```
/reasoning           - Открыть меню режимов
/reasoning_basic     - ⚡ Быстрый ответ
/reasoning_math      - 📊 Пошаговый ответ
/reasoning_strategic - 🎯 Составление промпта
/reasoning_creative  - 👥 Мнение экспертов
/normal              - Выйти из reasoning режима
/clear               - Очистить историю
```

### Особенности:

✅ Отдельная история для каждого пользователя
✅ Автоматическая очистка истории при смене режима
✅ PDF генерация для длинных ответов (>4000 символов)
✅ Приоритет reasoning режима над другими
✅ Raw ответы без парсинга
✅ Команды не попадают в Claude API
✅ Поддержка русского языка во всех режимах
