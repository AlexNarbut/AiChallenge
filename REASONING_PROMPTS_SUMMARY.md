# Reasoning Mode - Описание системных промптов

## Обзор

Все системные промпты созданы и настроены для решения логических задач. Каждый режим имеет уникальный подход.

---

## 1. ⚡ Быстрый ответ (`/reasoning_basic`)

**Файл:** `reasoning_basic.txt` (1.7 KB)

**Назначение:** Прямые и лаконичные ответы без избыточных рассуждений.

**Ключевые характеристики:**
- Минимум слов - максимум смысла
- Краткий анализ (1-2 предложения)
- Прямое применение логики
- Точный финальный ответ

**Формат ответа:**
```
[Краткий анализ задачи]
[Применение логики]
Ответ: [Точное решение]
```

**Когда использовать:**
- Нужен быстрый ответ на понятную задачу
- Не требуются подробные объяснения
- Важна скорость и конкретика

---

## 2. 📊 Пошаговый ответ (`/reasoning_math`)

**Файл:** `reasoning_mathematical.txt` (3.0 KB)

**Назначение:** Детальное пошаговое решение с рассуждениями на каждом этапе.

**Ключевые характеристики:**
- Разбивка на четкие пронумерованные этапы
- Объяснение ЧТО делаем и ПОЧЕМУ
- Промежуточные выводы на каждом шаге
- Педагогический подход

**Формат ответа:**
```
📋 АНАЛИЗ ЗАДАЧИ:
- Что дано
- Что требуется найти
- Ограничения

🔍 ПОШАГОВОЕ РЕШЕНИЕ:

Шаг 1: [Название]
- Что делаем: [действие]
- Почему: [обоснование]
- Вывод: [результат]

Шаг 2: [Название]
...

✅ ИТОГОВЫЙ ОТВЕТ:
[Финальное решение]

🔎 ПРОВЕРКА:
[Верификация]
```

**Когда использовать:**
- Нужно понять логику решения
- Образовательные цели
- Сложные задачи требующие детализации
- Когда важен процесс, а не только результат

---

## 3. 🎯 Составление промпта (`/reasoning_strategic`)

**Файл:** `reasoning_strategic.txt` (5.6 KB)

**Назначение:** Создание оптимальных промптов для других языковых моделей.

**Ключевые характеристики:**
- AI создает промпт для ДРУГОЙ модели
- Использует техники промпт-инжиниринга
- Структурирует задачу максимально четко
- Дает пояснения к промпту

**Формат ответа:**
```
📝 МОЙ АНАЛИЗ ЗАДАЧИ:
[Анализ: что требуется, подводные камни]

---

🎯 СГЕНЕРИРОВАННЫЙ ПРОМПТ ДЛЯ LLM:

[Полный промпт для другой модели]

---

💡 ПОЯСНЕНИЯ К ПРОМПТУ:
- Почему структурирован так
- Используемые техники
- На что направлен
```

**Техники промпт-инжиниринга:**
- Chain-of-Thought (пошаговое мышление)
- Role-playing (назначение роли)
- Structured output (структура ответа)
- Self-verification (самопроверка)
- Decomposition (декомпозиция задачи)

**Когда использовать:**
- Нужен промпт для использования в другой LLM
- Изучение промпт-инжиниринга
- Оптимизация формулировки задачи
- Создание шаблонов для повторного использования

---

## 4. 👥 Мнение экспертов (`/reasoning_creative`)

**Файл:** `reasoning_creative.txt` (6.9 KB)

**Назначение:** Решение через панель из 4 экспертов разных специализаций с финальным синтезом.

**Панель экспертов:**

1. 👨‍🔬 **Математик-логик** (Профессор Алексей Логин)
   - Формальная логика, математические доказательства
   - Строгий, структурированный подход

2. 🧠 **Когнитивный психолог** (Доктор Анна Мыслина)
   - Паттерны мышления, когнитивные искажения
   - Эмпатичный, фокус на процессе познания

3. 💻 **Программист-алгоритмист** (Дмитрий Кодов)
   - Алгоритмы, структуры данных
   - Системный подход, вычислительное мышление

4. 🎓 **Философ-аналитик** (Профессор Мария Разумова)
   - Концептуальный анализ, логика рассуждений
   - Глубинный анализ, критическое мышление

**Формат ответа:**
```
📋 ФОРМУЛИРОВКА ЗАДАЧИ:
[Четкое изложение]

---

👥 МНЕНИЯ ЭКСПЕРТОВ:

👨‍🔬 Математик-логик:
"[Анализ от первого лица]"
Ключевые моменты:
- [Инсайт 1]
- [Решение]

🧠 Когнитивный психолог:
"[Анализ от первого лица]"
...

💻 Программист-алгоритмист:
"[Анализ от первого лица]"
...

🎓 Философ-аналитик:
"[Анализ от первого лица]"
...

---

🎯 СИНТЕЗИРОВАННОЕ РЕШЕНИЕ:

Интеграция подходов:
- От математика: [что взяли]
- От психолога: [что взяли]
- От программиста: [что взяли]
- От философа: [что взяли]

Итоговый ответ: [Решение]
Обоснование: [Почему это решение лучшее]
```

**Когда использовать:**
- Комплексные задачи с разными аспектами
- Нужен многогранный взгляд
- Интересно увидеть разные подходы
- Задача требует междисциплинарного анализа

## Технические детали

### Загрузка промптов
Все промпты загружаются при старте приложения через `FormatPromptLoader`:
- Автоматическая загрузка из `src/main/resources/`
- Кэширование в памяти
- Доступ по ключу: `reasoning_basic`, `reasoning_mathematical`, `reasoning_strategic`, `reasoning_creative`

### Приоритет использования
```kotlin
when {
    reasoningType != null -> reasoning prompt  // Highest priority
    isExpertMode -> expert prompt
    else -> format prompt (json/xml/text)
}
```

### Обход парсинга
Reasoning режимы (как и expert mode) возвращают RAW ответ без парсинга через ResponseParser.

## Рекомендации по использованию

### Для пользователей:
1. **Быстрый вопрос?** → Используйте ⚡ Быстрый ответ
2. **Хотите понять логику?** → Используйте 📊 Пошаговый ответ
3. **Нужен промпт для ChatGPT/Claude?** → Используйте 🎯 Составление промпта
4. **Сложная задача?** → Используйте 👥 Мнение экспертов

### Для разработчиков:
- Промпты можно свободно редактировать в `.txt` файлах
- Изменения применяются после перезапуска приложения
- Можно добавлять новые режимы через конфигурацию
- Следите за размером ответов - используйте PDF для длинных
