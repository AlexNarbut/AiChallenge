# Quick Start - Reasoning Mode

## Быстрый старт

### 1. Запуск бота

```bash
TELEGRAM_BOT_TOKEN=your_token CLAUDE_API_KEY=your_key ./gradlew bootRun
```

### 2. Использование в Telegram

1. Откройте бота в Telegram
2. Отправьте `/start` для инициализации
3. Отправьте `/reasoning` для входа в режим Reasoning
4. Выберите один из 4 режимов:

---

## 🎯 Быстрый выбор режима

### ⚡ `/quick_answer` - Быстрый ответ
**Когда использовать:** Нужен быстрый, прямой ответ

**Пример:**
```
Пользователь: "Если все кошки - животные, а Мурка - кошка, то Мурка - животное?"
Бот: "Задача на простой силлогизм. Применяем транзитивность: если A⊆B и C∈A, то C∈B.
Ответ: Да, Мурка - животное."
```

---

### 📊 `/step_by_step` - Пошаговый ответ
**Когда использовать:** Нужно понять процесс решения

**Пример:**
```
Пользователь: "У фермера есть курицы и кролики, всего 20 голов и 56 лап. Сколько кроликов?"

Бот:
📋 АНАЛИЗ ЗАДАЧИ:
- Дано: 20 животных, 56 лап
- Найти: количество кроликов
- Курицы: 2 лапы, Кролики: 4 лапы

🔍 ПОШАГОВОЕ РЕШЕНИЕ:

Шаг 1: Составляем систему уравнений
- Что делаем: Обозначаем кур за К, кроликов за Р
- Почему: Нужны две переменные для двух неизвестных
- Уравнения: К + Р = 20, 2К + 4Р = 56

Шаг 2: Решаем систему
...

✅ ИТОГОВЫЙ ОТВЕТ: 8 кроликов
```

---

### 🎯 `/prompt_engineer` - Составление промпта
**Когда использовать:** Нужен промпт для использования в другой LLM

**Пример:**
```
Пользователь: "Задача про Ханойские башни с 3 дисками"

Бот:
📝 МОЙ АНАЛИЗ ЗАДАЧИ:
Классическая рекурсивная задача. Нужен промпт, который направит модель на алгоритмическое решение.

🎯 СГЕНЕРИРОВАННЫЙ ПРОМПТ ДЛЯ LLM:

"Ты - эксперт по алгоритмам и рекурсии. Реши задачу про Ханойские башни:

Дано:
- 3 стержня (A, B, C)
- 3 диска разного размера на стержне A
- Можно перемещать только верхний диск
- Больший диск нельзя класть на меньший

Задача: Переместить все диски на стержень C

Подход:
1. Определи базовый случай
2. Примени рекурсивную стратегию
3. Покажи последовательность ходов
4. Объясни сложность алгоритма

Ответ предоставь в формате:
- Алгоритм (словесное описание)
- Пошаговая последовательность ходов
- Анализ временной сложности"

💡 ПОЯСНЕНИЯ:
- Использована техника Chain-of-Thought
- Структурирован вывод
- Задан контекст экспертизы
```

---

### 👥 `/expert_panel` - Мнение экспертов
**Когда использовать:** Нужен многогранный анализ сложной задачи

**Пример:**
```
Пользователь: "Парадокс близнецов в теории относительности"

Бот:
📋 ФОРМУЛИРОВКА ЗАДАЧИ:
Один близнец летит в космос на околосветовой скорости, другой остается на Земле.
По возвращении космонавт моложе. Почему?

👥 МНЕНИЯ ЭКСПЕРТОВ:

👨‍🔬 Математик-логик (Алексей Логин):
"Я подхожу к этому через преобразования Лоренца. Время в движущейся системе
отсчета замедляется по формуле t' = t/√(1-v²/c²). Это математически строгое
следствие из постулатов СТО..."

🧠 Когнитивный психолог (Анна Мыслина):
"Интересно, что наша интуиция сопротивляется этому. Мы привыкли к абсолютному
времени - это когнитивная предпосылка, сформированная опытом..."

💻 Программист-алгоритмист (Дмитрий Кодов):
"Я бы смоделировал это как две параллельные временные линии с разными тактовыми
частотами. Один clock идет быстрее, другой медленнее..."

🎓 Философ-аналитик (Мария Разумова):
"Здесь важно различать концептуально 'время' и 'измерение времени'.
Парадокс возникает из-за смешения этих понятий..."

🎯 СИНТЕЗИРОВАННОЕ РЕШЕНИЕ:
[Объединение всех подходов в полное объяснение]
```

## 📌 Полезные команды

- `/reasoning` - Открыть меню режимов
- `/normal` - Вернуться в обычный режим
- `/clear` - Очистить историю диалога
- `/start` - Перезапустить бота

---

## 🔧 Настройка промптов

Все системные промпты находятся в `src/main/resources/systemPrompts/`:

```
reasoning_quick_answer_system_prompt.txt      - Быстрый ответ
reasoning_step_by_step_system_prompt.txt      - Пошаговый ответ
reasoning_prompt_engineer_system_prompt.txt   - Составление промпта
reasoning_expert_panel_system_prompt.txt      - Мнение экспертов
```

Отредактируйте файл → Перезапустите приложение → Промпт обновлён!

---

## 💡 Советы

1. **Быстрый ответ** - используйте для простых логических вопросов
2. **Пошаговый ответ** - идеален для обучения и понимания
3. **Составление промпта** - полезен при работе с другими LLM
4. **Мнение экспертов** - для сложных междисциплинарных задач

---

## ⚠️ Важно

- Длинные ответы (>4000 символов) автоматически отправляются как PDF
- История очищается при переключении режимов
- Reasoning режимы работают независимо от Response Format (json/xml/text)
- Каждый пользователь имеет свой отдельный режим и историю
