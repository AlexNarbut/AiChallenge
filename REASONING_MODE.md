# Reasoning Mode - Implementation Summary

## Overview
Добавлена новая функциональность "Reasoning Mode" с 4 специализированными подрежимами для решения логических задач.

## Структура

### 4 подрежима:

1. **Быстрый ответ** (`/reasoning_basic`)
   - Прямые и лаконичные ответы на логические задачи
   - Минимум рассуждений - максимум точности
   - Файл промпта: `reasoning_basic.txt`
   - **Подход:** Нейронка дает ответ напрямую без длинных объяснений

2. **Пошаговый ответ** (`/reasoning_math`)
   - Детальное пошаговое решение с рассуждениями
   - Объяснение логики каждого шага
   - Файл промпта: `reasoning_mathematical.txt`
   - **Подход:** Решение разбивается на четкие этапы с полными пояснениями

3. **Составление промпта** (`/reasoning_strategic`)
   - Создание оптимальных промптов для других LLM
   - Экспертиза в промпт-инжиниринге
   - Файл промпта: `reasoning_strategic.txt`
   - **Подход:** AI создает детальный промпт, который поможет другой модели решить задачу

4. **Мнение экспертов** (`/reasoning_creative`)
   - Решение через панель из 4 экспертов разных специализаций
   - Синтез различных подходов в единое решение
   - Файл промпта: `reasoning_creative.txt`
   - **Подход:** Математик-логик, психолог, программист и философ высказывают мнения, которые затем синтезируются

### Детали подрежимов:

#### 1. Быстрый ответ (Basic)
Нейронка анализирует задачу и сразу дает конкретный ответ:
- Краткий анализ (1-2 предложения)
- Применение логики
- Точный финальный ответ
- Никаких избыточных объяснений

#### 2. Пошаговый ответ (Mathematical)
Детальное решение с полной структурой:
- 📋 Анализ задачи
- 🔍 Пошаговое решение (каждый шаг с объяснением ЧТО и ПОЧЕМУ)
- ✅ Итоговый ответ
- 🔎 Проверка решения

#### 3. Составление промпта (Strategic)
Создание промпта для другой LLM:
- 📝 Анализ задачи пользователя
- 🎯 Сгенерированный промпт для LLM
- 💡 Пояснения к промпту (используемые техники)
- Применяет Chain-of-Thought, Role-playing, Structured output

#### 4. Мнение экспертов (Creative)
Панель из 4 экспертов:
- 👨‍🔬 Математик-логик (формальная логика)
- 🧠 Когнитивный психолог (паттерны мышления)
- 💻 Программист-алгоритмист (алгоритмическое мышление)
- 🎓 Философ-аналитик (концептуальный анализ)
- 🎯 Синтезированное решение

## Команды

- `/reasoning` - Открыть меню выбора режима
- `/quick_answer` - ⚡ Быстрый ответ
- `/step_by_step` - 📊 Пошаговый ответ
- `/prompt_engineer` - 🎯 Составление промпта
- `/expert_panel` - 👥 Мнение экспертов
- `/normal` - Вернуться в обычный режим

## Использование

1. Пользователь отправляет `/reasoning`
2. Бот показывает меню с 4 вариантами
3. Пользователь выбирает нужный режим (например, `/reasoning_math`)
4. Бот активирует режим и очищает историю
5. Пользователь задаёт логическую задачу
6. Бот обрабатывает её с соответствующим системным промптом
7. Пользователь может продолжать диалог в рамках выбранного режима
8. Для выхода: `/normal` или `/reasoning` (для переключения)

## Настройка системных промптов

Все системные промпты можно настроить, редактируя соответствующие `.txt` файлы в `src/main/resources/`.

Каждый файл содержит:
- Описание роли AI
- Основные принципы и подходы
- Методологию решения задач
- Специфичные техники и фреймворки

## Комбинирование промптов режимов и форматов

**ОБНОВЛЕНО:** Response Format теперь применяется ВСЕГДА, независимо от режима.

### Логика комбинирования:

1. **Mode Prompt** (опциональный):
   - Reasoning mode → reasoning-специфичный промпт
   - Expert mode → expert-специфичный промпт
   - Normal mode → пустой промпт

2. **Format Prompt** (опциональный):
   - JSON format → JSON format requirements
   - XML format → XML format requirements
   - Text format → пустой промпт

3. **Итоговый System Prompt**:
   ```
   [Mode Prompt]

   [Format Prompt]
   ```

   Если оба промпта присутствуют, они объединяются с разделителем `\n\n`.

### Примеры комбинаций:

| Режим | Format | Итоговый System Prompt |
|-------|--------|------------------------|
| Normal | text | (пусто) |
| Normal | json | JSON format prompt |
| Expert | json | Expert prompt + JSON format prompt |
| Reasoning (basic) | xml | Quick Answer prompt + XML format prompt |

**Важно:** Response format применяется НЕЗАВИСИМО от режима. Reasoning режим больше НЕ переопределяет response format.
